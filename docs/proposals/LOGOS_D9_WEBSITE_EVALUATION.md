## Observed evidence

- Shape fixture RED: five tests failed on the missing validator, zero skipped.
- Identical shape tests GREEN on d9 and admitted132: five passed, zero failed or
  skipped, one finite Boolean property proven. Only d9's output additionally
  reports five interpreter/VM agreements.
- Native PG16 contract RED: seven methods, five passed and two failed in 2.582s.
  The stub neither returned the real board nor connected to the controlled peer.
- Native compile RED: two E0382 move/borrow errors, then E0597 on a subsequent
  attempt. Exact MaCSad source history is retained; no generated Rust is included.
- Native build GREEN: final MaCSad source uses a named rows value, an owned
  workspace-text parameter, and a named query-result value to avoid those
  candidate compiler failures. Stable and actual binaries matched, and the
  retained locked/offline rebuild checks passed.
- Unchanged native PG16 contract GREEN: seven methods passed in 7.877s. It
  checked the real read-only viewer/schema, exact deterministic projection of
  three closed fixture cases, rejection of alternate workspace/unsafe URL/invalid
  argument forms, and connection/failure behavior against a controlled silent
  peer. Per-test fingerprints of all 47 base tables remained unchanged. The
  source-before/source-after manifests matched and only the owned PostgreSQL
  test instance was shut down, with its PID file subsequently absent.

The wire contains case/task projection fields and the exact titles; it does not
expose actor/identity records or grant authority. The alternate-workspace test
proves this fixed-workspace evaluation rejects an override before connecting,
not general tenant isolation. The three closed fixture cases are not live
